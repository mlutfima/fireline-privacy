🔐 Safety & transparency

No simulated live readings. This static website does not store readings on a shared server. Manual records and channel settings stay in your browser. A public ThingSpeak channel, if connected, exposes that channel's telemetry to everyone with access. Do not put Wi-Fi passwords or API WRITE keys in this page. App controls are logs, not remote physical control. Automatic fish feeding and grow light actuation require a separate secure device integration.
